# Support

## Questions and ideas

Use [GitHub Discussions](https://github.com/DragonPlayz-1/alpha-terminal/discussions) for setup questions, architectural discussion, and sharing how you use the simulator.

Start with the [quick start](README.md#quick-start), [configuration reference](docs/configuration.md), and [operations runbook](docs/operations.md). Include your Node/PostgreSQL versions and whether both web and worker are running.

## Reproducible bugs

Open a [bug report](https://github.com/DragonPlayz-1/alpha-terminal/issues/new?template=bug_report.yml) with:

- Release/commit and environment versions.
- Minimal reproduction steps and expected/actual behavior.
- The affected screen, account scope type, and order type when relevant.
- Redacted logs or a screenshot using a disposable demonstration account.
- Relevant local test results, if available.

Never include `.env`, passwords, tokens, session cookies, personal financial information, or private database URLs.

## Feature proposals

Use the [feature request form](https://github.com/DragonPlayz-1/alpha-terminal/issues/new?template=feature_request.yml). Explain the user problem, the proposed workflow, and how it fits the virtual-funds simulator. Focused improvements with examples and tests are easier to review.

## Security issues

Follow [SECURITY.md](SECURITY.md) and report privately through GitHub's security reporting channel. Do not publish exploit details in an ordinary issue.

## Project scope

This is an open-source educational project maintained on a best-effort basis. It does not provide brokerage services, trading advice, real-order execution, or a hosted-service uptime guarantee. Contributions are welcome under [CONTRIBUTING.md](CONTRIBUTING.md).
